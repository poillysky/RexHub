# RexHub iOS App UI 视觉效果与质感规范

> 配套文档：[产品需求基线](./product-requirements.md) ｜ [架构设计原则](./ios-app-blueprint.md)
> 适用端：iOS 17+ / SwiftUI / iPhone + iPad
> Token 基线：[RexTheme.swift](../RexHub/Core/Design/RexTheme.swift)
> 更新日期：2026-11-01

---

## 1. 质感从哪里来

借鉴飞牛（fnOS）iOS App 的调研结论，**质感不来自装饰，来自三件事**：

1. **结构稳定**：顶栏 → 内容卡片 → 底部 Tab，三层在所有页面复用，用户永远知道自己在哪。
2. **场景配色**：工具页浅色管理，影视页纯黑观影，海报是唯一视觉重心。
3. **完成度高**：键盘避让、横竖屏切换、权限失败、空态、封面加载失败都有交代。

对应到 RexHub：

| 借鉴 | 不借鉴 |
| --- | --- |
| 紧凑顶栏（搜索 + 圆形操作）替代大标题 | 10+ 入口的多应用彩色宫格 |
| 白卡 + 浅灰底，无阴影分层 | 蓝色品牌色 + 满屏彩色图标体系 |
| 细线圆环 + 等宽数字展示状态 | 自定义 Tab / 手写玻璃材质 |
| 系统 `TabView`，4 项以内 | 全屏阻塞式隐私/引导页 |
| 工具页浅色、影视页深色按场景切换 | 花哨渐变背景、玻璃拟态堆叠 |

五条设计原则：

1. **内容优先**：海报、文件名、进度是第一视觉层，容器退到背景。
2. **一屏一焦点**：每屏只有一处最亮——主按钮或主内容。
3. **灰度做层次**：底色、描边、留白分层，不靠彩色色块堆叠。
4. **状态完整**：加载、空、错误、离线四态齐全，缺一态就显廉价。
5. **原生习惯优先**：大标题、侧滑返回、下拉刷新、长按菜单、系统 ShareLink。

目标：**一眼看上去像成熟商业产品，而不是个人 Demo**。

## 2. 视觉方向

| 维度 | 结论 |
| --- | --- |
| 关键词 | 干净、克制、专业、数据感 |
| 参考对象 | 群晖 DSM、Plex、Infuse、飞牛 fnOS |
| 场景配色 | 工具页浅色（白卡 + 灰底），影视/播放页深色（黑底 + 海报） |
| 视觉主张 | 中性底色 + 单一品牌蓝，信息密度高于社交类 App |
| 反面清单 | 玻璃拟态堆叠、大面积彩色渐变背景、满屏彩色图标、花哨阴影、无意义动效 |

> 管理台沿用 `#3B82F6`；**iOS 端以 `RexTheme.swift` 的 `#0066FF` 为准**，两端不互相覆盖。

## 3. 页面骨架

```text
一级页（影视 / 短剧 / 网盘 / 更多）
┌──────────────────────────────┐
│ 顶栏：品牌/标题 + 状态位 + 1~2 圆形图标 │
│ 内容区：白卡 / 列表 / 海报墙    │
│ 底部系统 Tab（4 项以内）        │
└──────────────────────────────┘

二级页：系统导航栏（返回 + 居中标题 + 右侧操作）
播放页：纯黑全屏，无卡片、无 Tab
```

- 三层结构在所有页面复用，不逐页发明新布局。
- 卡片是信息容器，不是装饰：一张卡只表达一件事。
- 深浅色按场景切换，不按用户偏好强制全局深色。

## 4. Design Tokens

### 4.1 颜色

| 语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 品牌蓝 | `#0066FF` | 同左 | 主操作、选中态、链接、进度 |
| 品牌蓝亮 | `#2E7BFF` | 同左 | 渐变起点、轻微强调 |
| 浅蓝 | `#E6F0FF` | 同左（降透明度） | 选中背景、弱提示 |
| 页面背景 | `#F2F5FA` | `#0E1116` | 页面底色 |
| 卡片/表面 | `#FFFFFF` | `#171B22` | 卡片、导航栏、输入区 |
| 输入框填充 | `#F2F5FA` | `#1C222B` | TextField 底色 |
| 主要文字 | `#0F172A` | `#F2F5FA` | 标题、正文 |
| 次要文字 | `#8B8F98` | `#8B93A1` | 说明、占位、时间 |
| 分割线 | `#E5E7EB` | `#2A3038` | 列表分隔、卡片描边 |
| 成功 | `#10B981` | 同左 | 在线、备份完成 |
| 警告 | `#F59E0B` | 同左 | 容量告警、进行中 |
| 错误 | `#EF4444` | 同左 | 失败、删除确认 |

**用色纪律**

1. 品牌渐变只出现在主按钮、App 图标、品牌 Logo 三处，不做页面背景。
2. 状态色只表意：绿=正常，橙=注意，红=危险；同一行最多两种强调色。
3. 大面积区域只用中性色。
4. 页面代码禁止 `.white` / `.black` 硬编码，全部走语义色。

### 4.2 字体

| 层级 | 规格 | 用途 |
| --- | --- | --- |
| 标题 1 | 32 / Semibold | 页面主标题、登录品牌名 |
| 标题 2 | 24 / Semibold | 模块标题 |
| 标题 3 | 18 / Medium | 卡片标题、列表标题 |
| 正文 | 16 / Regular | 正文、输入内容 |
| 辅助 | 14 / Regular | 说明、时间、状态 |

- 中文行高 1.3–1.4，用 `.lineSpacing(4)` 微调。
- 容量、码率、时长、百分比统一 `.monospacedDigit()`，刷新时宽度不跳动。
- 正文不用纯黑，用 `primaryText`。
- 过长的单行文本优先截断，不缩小字号。
- 固定字号只允许用于品牌字与装饰数字。
- 表中数值为 Default 档基准值；实现时映射为 Dynamic Type 相对字号，放大规则见 8.4。

### 4.3 间距与圆角

间距只取 4 的倍数：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48`。

| 场景 | 值 |
| --- | --- |
| 页面左右边距 | 20（手机）/ 24（iPad） |
| 卡片内 padding | 16 |
| 卡片之间 | 12 |
| 区块之间 | 24 |
| 页面顶部起始 | 12–32（有导航栏时取小） |

品牌页（启动 / 登录）顶部留白可用 48–64，让品牌块垂直居中；其余页面不套用这条例外。

圆角固定五档：

| Token | 值 | 用途 |
| --- | --- | --- |
| `RexRadius.control` | 14 | 输入框、按钮 |
| `RexRadius.card` | 16 | 卡片、列表容器 |
| `RexRadius.panel` | 24 | 设置中心的分组面板（更多页与二级页） |
| `RexRadius.iconTile` | 22 | 功能图标底（44×44） |
| `RexRadius.brand` | 26 | App 图标、品牌方块（96×96） |

### 4.4 阴影

- 默认**不用阴影**，用底色差与 1px 描边分层（与 fnOS 白卡质感一致）。
- 仅两类元素允许投影：
  1. 主按钮：`brandBlue 30% / radius 16 / y 8`
  2. 悬浮层（播放控制条、悬浮分段控件）：`black 8% / radius 20 / y 4`
- 禁止彩色光晕、多层堆叠阴影。
- 深色外观下阴影不可见，统一取消，改用 1px `divider` 描边或提高表面亮度区分层次（见 4.9）。

### 4.5 动效与触感

| 项 | 规范 |
| --- | --- |
| 时长 | 150ms（按压）/ 200–300ms（页面与状态） |
| 曲线 | `easeOut`；弹性只用于品牌入场 |
| 属性 | 只动 `opacity` 与 `transform`，不动布局 |
| 减弱动效 | `accessibilityReduceMotion` 开启时取消位移与循环动画 |
| 触感 | 成功 `.success`、警告 `.warning`、轻操作 `.light`、删除确认 `.medium` |

### 4.6 图标

| 尺寸 | 用途 |
| --- | --- |
| 12 | 行内状态点、标签内小图标 |
| 16 | 输入框前缀、列表副图标 |
| 20 | 卡片标题行、工具条 |
| 24 | 功能入口（iconTile 内） |
| 28–32 | 空态、错误页插图 |

- 只用 SF Symbols，一个语义固定一个符号，不自绘 SVG、不用第三方图标集。
- 默认线性；仅 Tab 选中态与明确"已选"场景可用填充，同一区域不混用。
- 线宽跟随系统 `weight`（Regular / Medium），不手动改 stroke。
- 图标与文字间距 8pt；用 `.firstTextBaseline` 对齐，不靠 padding 硬凑。
- 图标不单独承载唯一信息：要么配文字，要么给 `accessibilityLabel`。
- 禁止多彩图标、3D 拟物图标、为装饰而加的图标。

### 4.7 布局与栅格

- 基准 4pt，所有间距与尺寸落在 4 的倍数。
- 手机单列：内容宽 = 屏宽 − 40（左右各 20）。
- iPad：内容最大宽 720 居中；分栏时侧栏 320 + 详情区。
- 海报网格：2:3 比例，最小宽 100，间距 12；手机 3 列，iPad 5–6 列。
- 列表行高：52（设置）/ 60（文件）/ 72（带进度或双行副标题）。
- 断点：≤ 430 单列卡片；431–768 双列；> 768 分栏。
- 内容不侵入底部安全区；只有播放页与全屏视图可以压到底。

### 4.8 数值与文本格式

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 文件大小 | 1024 进制、1 位小数、单位大写 | `1.4 GB` |
| 时长 | < 1h 用 `分:秒`，≥ 1h 用 `时:分:秒` | `12:04` / `1:02:33` |
| 百分比 | 整数 | `68%` |
| 日期 | 今天 / 昨天 → `10月28日` → `2025年10月` | — |
| 码率 | 1 位小数 | `8.5 Mbps` |
| 大数 | ≥ 1 万用「万」 | `1.2 万` |

- 全部数值加 `.monospacedDigit()`；负号用 `−`，不用连字符。
- 数字与单位之间留半角空格；中文标点用全角，句中英文与数字用半角。
- 时间按本地时区显示，不出现 UTC 或服务器时区。

### 4.9 深浅色与外观

- 默认跟随系统；**播放页强制深色**，工具页不强制全局深色。
- 两套外观共用同一套语义色名，页面代码不读 `colorScheme` 改色（背景与插图除外）。
- 深色下不叠阴影（不可见且发灰），改用 1px `divider` 描边；白卡改用 `surface`。
- 品牌蓝两套外观都保持 `#0066FF`；浅蓝底在深色下统一降到 8–12% 透明度。
- 深色下海报不加白色描边，靠留白与圆角区分；不把海报做暗角或调色。
- 切换到深色时不出现"白闪"：`background` 由语义色铺底，禁止写死 `.white`。

### 4.10 层级与浮层

| 层级 | 内容 | 规则 |
| --- | --- | --- |
| 0 | 页面背景 | 恒定最底 |
| 1 | 卡片 / 列表 | 与背景靠底色差分层 |
| 2 | 吸顶顶栏、悬浮操作条 | 滚动后出现，带 1px `divider` |
| 3 | Toast、行内浮层 | 安全区下方，不遮挡顶栏操作 |
| 4 | sheet、弹窗 | 系统管理，自带上滑转场 |
| 5 | 全屏播放、115 授权 | 独占层级，隐藏 Tab 与状态栏 |

- 同一时刻只允许一层浮层：Toast 不叠加在 sheet 上，sheet 打开时改行内提示。
- 浮层出现时背景内容压暗 20%，不做模糊堆叠、不做多层卡片套卡片。
- 键盘弹起时浮层随内容上移，不被遮挡；行内错误优先于 Toast。
- 层级用系统容器（`.sheet` / `.fullScreenCover` / `.overlay`），不靠争抢 `zIndex` 排版。

## 5. 组件质感

### 5.1 按钮

| 类型 | 样式 | 使用场景 |
| --- | --- | --- |
| 主按钮 | 品牌渐变填充，白字 17 Semibold，高 54，圆角 14 | 每屏最多 1 个 |
| 次按钮 | `field` 填充，主要文字色 | 取消、次要确认 |
| 文字按钮 | 品牌蓝 14 Medium | 忘记密码、去注册、更多 |
| 图标按钮 | 36×36 圆形，命中区 ≥ 44×44 | 顶栏操作 |

- 按压反馈：`scale 0.98 + opacity 0.9`，150ms。
- 不可用态：填充切 `field`，文字 `secondaryText`，去掉阴影。
- 请求中：按钮内嵌 `ProgressView`，禁用重复点击。

### 5.2 输入框

- 高 56，圆角 14，填充 `field`，无边框。
- 左侧 16pt 线性图标，右侧可放操作图标（密码可见）。
- 聚焦：1.5pt `brandBlue 60%` 描边，不发光。
- 错误：描边换 `error 65%`，下方 12pt 红色说明，不弹窗。
- 禁用：整体 `opacity 0.45`，不响应点击。

### 5.3 卡片与列表

- 卡片：`surface` 底、圆角 16、1px `divider` 描边、内边距 16。
- 二级容器（白卡里的小块）用 `field`，形成两层结构。
- 列表行高 60：缩略图 44（圆角 10）→ 标题 16 + 副标题 14 灰 → 右侧状态/箭头。
- 分隔线从文字左边缘缩进，不贯穿整行。
- 文件类型图标：功能入口用「渐变底 + 白色线稿」，列表内用「浅蓝底 + 品牌蓝线稿」。
- 封面/缩略图加载失败必须给类型图标占位，不留白块（fnOS 版本日志中的高频问题）。

### 5.4 状态标签

- 胶囊形，高 22，左右 padding 10，字号 12。
- 弱化底色：成功 `success 12%` + 深绿字；警告、错误同理。
- 同一行最多 2 个，超出显示「+N」。

### 5.5 导航栏与 Tab

- 一级页面用紧凑工具条：品牌/标题 + 状态位 + 1–2 个圆形图标，不用 Large Title（结构见 5.7）。
- 二级页面用系统导航栏：返回 + 居中标题（17 Semibold）+ 右侧操作。
- 保留系统侧滑返回，不覆盖手势。
- **不手写玻璃材质**，交给系统组件随 iOS 版本自动适配。

**底部 Tab 栏**

| 项 | 规范 |
| --- | --- |
| 数量 | 2–4 项；到 5 项时把次要项收进「更多」，不做 5 项以上 |
| 组成 | 图标 + 文字标签，标签 2–4 字；不用纯图标 Tab |
| 图标 | 系统尺寸 24–25pt；未选中线性 `secondaryText`，选中填充 `brandBlue` |
| 背景 | 系统 `TabView` 默认材质，不自定义高度、圆角、毛玻璃 |
| 分隔 | 交给系统（hairline / 材质分层），浅色深色都不额外加描边 |
| 高度 | 49pt + 底部安全区；内容不侵入，键盘弹起时随系统避让 |
| 命中 | 每项等宽均分，热区覆盖整个 Tab 项，≥ 44 高 |

- 顺序固定：**影视 → 短剧 → 网盘 → 更多**，当前实现即此 4 项；新增页只在末尾追加，不随版本乱序。
- 选中态只用「填充图标 + 品牌蓝」表达：不加胶囊底、不加下划线、不缩放、不弹跳。
- 点击已选中的 Tab：回到该 Tab 根页面并滚动回顶部，给一次 `.light` 触感；已在根页面且已回顶时不再动作。
- 切换 Tab 保留各自导航栈与滚动位置，不重建列表（见 12.5、12.10）。
- 进入二级页、播放页、115 授权全屏时 Tab 隐藏；返回后恢复，不允许 Tab 覆盖在二级页之上。
- 有输入框的页面不把 Tab 顶到键盘上方；键盘避让交给系统，不手动隐藏 Tab。
- 角标只用小圆点（见 5.15），且红点必须有能清除它的消息入口，不做"永不清除"的提示。
- 标签短于 4 字是硬约束：Dynamic Type 放大时系统不缩放 Tab 标签，长文案直接被截断。
- iPad 宽 ≥ 768 时改用侧栏（`NavigationSplitView` 或 TabView 的 sidebar 适配），不同时出现底部 Tab 与侧栏。
- Tab 不承载即时动作（播放、上传、刷新），这些放页面内按钮。

**底部 Tab 禁止**

- 自定义整体背景、渐变、彩色图标、悬浮胶囊式 Tab。
- 超过 4 项、Tab 内再嵌 Tab、用 Tab 做登录与引导页切换。
- 在 Tab 上放营销文案、活动角标或未读数字。

### 5.6 弹窗与反馈

| 场景 | 方式 |
| --- | --- |
| 危险操作（删除、解绑） | 系统 `alert`，红色破坏按钮 |
| 表单/选择 | `.sheet` + `presentationDetents([.medium])` |
| 沉浸式播放 | `.fullScreenCover` |
| 轻提示（复制成功） | 顶部 Toast，2 秒自动消失 |
| 空态 | `ContentUnavailableView` 或自定义空态 + 一个动作 |

### 5.7 顶栏

顶栏只解决三件事：**我在哪、当前状态如何、能做什么**。不承担内容展示。

| 形态 | 用于 | 结构 | 高度 |
| --- | --- | --- | --- |
| 品牌工具条（特殊） | 影视首页 | 品牌标 + 标题/问候 + 状态位 + 1–2 个圆形图标 + 搜索框 | 56 + 56 |
| 通用工具条 | 其余一级页（短剧 / 网盘 / 更多） | 无返回 + 居中标题 + 右侧快捷操作 | 52 |
| 通用工具条（二级） | 二级页（子文件夹 / 设置页） | 返回 + 居中标题 + 右侧快捷操作 | 52 |
| 隐藏 | 播放页 / 沉浸全屏 | 无顶栏，内容顶到安全区 | 0 |

顶栏是**固定在安全区下方的遮罩**，与内容区同级、不参与滚动。没有特殊要求时一律使用通用工具条 `RexNavBar`，页面只声明自己的快捷操作（`RexNavAction`，最多 2 个）；品牌工具条 `RexTopBar` 只保留给影视首页，页面不再自己拼 HStack。

**通用工具条结构**

```text
[‹]            页面标题             [快捷操作 1] [快捷操作 2]   52 高，surface + 1px 分隔线
44 命中区       17 Semibold 居中        36 圆形图标，命中 44
```

- 左侧：一级页留空，二级页显示返回；**返回只有图标，不写来源页名称**，避免和居中标题抢宽度。
- 中间：当前页标题，单行、超长截断，左右各预留 96pt 给两侧按钮。
- 右侧：只放当前页需要的快捷操作，一个图标只做一件事，最多 2 个，品牌蓝；不可用时降透明度到 35%。
- 通用工具条**不随滚动收拢**，高度固定 52；需要搜索与问候的页面才用品牌工具条。
- 快捷操作示例：网盘「刷新」、设置页「分享」、列表页「排序 / 筛选」；没有快捷操作时右侧留空，不补占位图标。

**融合感（硬约束）**

- 页面未滚动时：顶栏**透明、不画分隔线**，与页面底色连成一体，看不出边界。
- 页面上滑超过 8pt：顶栏 200ms `easeOut` 淡入 `surface` 底色与 1px 底部 `divider`，把标题和滚动内容分开。
- 回到顶部：恢复透明融合态；回弹未超过 8pt 不切换，避免临界抖动。
- 状态栏区域随顶栏一起变化：未滚动透出页面底色，滚动后铺 `surface`，不出现上下两块色。
- 滚动状态统一由 `rexScrollTracking(_:isScrolled:)` + `RexScrollOffsetReader` 提供，页面不重复写 `PreferenceKey`。
- 影视首页的收拢态天然满足这条：展开透明融合，收拢铺 `surface` + 分隔线。

**影视页顶栏结构（展开态）**

```text
[Logo 36] RexHub · 早上好，Rex            ● 在线        [头像]
          20 Semibold   12 次级            状态位 12     36 圆形，命中 44
[ 🔍 搜索电影、剧集                                    ]   44 高，field 填充
```

**收拢态**（内容滚动超过 8pt）

```text
[Logo 28] RexHub                        🔍   ● 在线    [头像]   52 高，surface + 1px 分隔线
          17 Semibold
```

收拢时：标题 20 → 17、Logo 36 → 28、问候与搜索框收起，右侧补一枚 36 圆形搜索图标（点击回到顶部并展开搜索）。整个过程 200ms `easeOut`，只动透明度、尺寸与高度，不做位移视差。

**动态信息规则**

1. 状态位同一时刻**只显示一个**，优先级：离线 / 未连接 > 同步中 > 存储告警 > 正常在线。
2. 文案固定词表：`在线` / `未连接` / `同步中 62%` / `存储余 12%`，不写长句。
3. 颜色：在线 `success`、告警 `warning`、异常 `error`、进行中品牌蓝 + 8pt 小菊花。
4. 数值一律 `.monospacedDigit()`，宽度变化不推动右侧图标。
5. 状态切换 200ms 淡入，不做数字滚动、不做闪红闪绿。
6. 数据刷新：健康检查 30s 一次，回到前台立即刷一次；请求失败保留上一次状态并降为灰色，不直接跳「未连接」。

**问候语**（一级页副标题）

- 5–11 早上好 / 11–13 中午好 / 13–18 下午好 / 18–23 晚上好 / 其余 夜深了。
- 昵称缺失时只显示问候，不显示「你好，」空壳。
- 问候语是可丢弃信息：宽度不足时先省略它。

**滚动与键盘**

- 展开态背景透明、高度 112（56 标题行 + 56 搜索行）；收拢态高度 52、铺 `surface` 底色 + 底部 1px `divider`。
- 收拢阈值 8pt，回弹未超过阈值不切换，避免抖动；切换统一 200ms，不做逐帧插值。
- 搜索框属于顶栏，随顶栏一起收拢，不单独吸顶；收拢后由搜索图标回到顶部承接。
- 键盘弹起时顶栏不跟随上移，只有内容区避让；滚动时键盘交互式收起。
- 二级页顶栏常驻 `surface` 底色与分隔线，不随滚动变化。

**返回按钮**

- **一级页（底部 Tab 直接打开的页面，即影视 / 短剧 / 网盘 / 更多）不显示返回**，用 Tab 或系统手势切换，不允许用返回按钮做 Tab 切换。
- **二级页（从一级页 push 进入的页面）显示返回**：只有 `chevron.left` 图标，17 Semibold，品牌蓝，命中区 44×44，位于标题左侧，不写文字。
- 返回语义是**导航栈回退**：点击 pop 到进入当前页之前的那一页，不在按钮上标注来源页名称。
- 保留系统侧滑返回，与按钮行为一致；根页面不显示返回。

**宽度不足的退让顺序**：省略问候 → 省略状态文字只留圆点 → 隐藏第二枚图标。品牌与主标题永不截断。

**禁止**

- 不做视差、不做毛玻璃堆叠、不做彩色整条顶栏。
- 图标不超过 2 个，不放营销文案、公告条、广告位。
- 不在顶栏展示需要横向滚动的信息（跑马灯、长文件名）。

### 5.8 列表与网格

- 三种密度：52（设置类）/ 60（文件类）/ 72（带进度或双行副标题）。
- 分组用白卡包裹，组间 24，组标题 13 `secondaryText`。
- 分隔线 1px `divider`，左缩进到内容起点；每组最后一行不画。
- 选中态：行背景切 `field`；编辑模式下右侧显示圆圈，不可选行 `opacity 0.4`。
- 网格项：2:3 封面 + 12pt 标题（1 行截断）+ 12pt 灰副标题，间距 12。
- 列表与网格互切时保持滚动位置，不回到顶部。
- 空列表不画分隔线、不留半截卡片。

### 5.9 表单控件

| 控件 | 规格 | 场景 |
| --- | --- | --- |
| Toggle | 系统样式，`tint` 品牌蓝，右对齐 | 开关项 |
| Segmented | 高 32，圆角 10，选中白底 | 2–4 项视图切换 |
| Picker | `.menu`，行内右侧显示当前值 + 箭头 | 清晰度、码率 |
| DatePicker | `.compact`，行内右侧显示日期 | 时间段筛选 |
| Slider | 轨道高 4，拇指 16，拖动时显示数值气泡 | 音量、亮度 |
| Stepper | 系统样式 | 并发数、重试次数 |
| 复选 | 18pt 自绘圆/方图标，整行可点 | 记住密码、多选 |

- 表单行：label 在左不换行（超长截断），控件在右。
- 必填项不加红色星号，用提交时提示或行内「必填」说明。
- 帮助文本 12 `secondaryText`，位于控件下方 4pt。
- 禁用：`opacity 0.45` + 不响应点击，并说明原因。

### 5.10 图片与封面

- 比例固定：海报 2:3、剧照 16:9、方形缩略图 1:1，禁止拉伸。
- 圆角：列表缩略图 10、卡片封面 12、全屏海报 0。
- 加载：先 `field` 底 + 类型图标，成功后 150ms 淡入，避免白块闪。
- 失败：保留类型图标占位，不显示红色叉号。
- 降采样到「显示尺寸 × 屏幕倍率」，滚动时不发起新请求。
- 视频封面右下角显示时长胶囊：高 18、字号 11、黑 60% 底白字。
- 不使用随机彩色块作占位，避免闪烁；首版不做模糊主色占位。

### 5.11 进度与数据可视化

- 环形：线宽 8（卡片）/ 6（行内），底环 `divider`，进度用品牌蓝圆头；中心数值 16 Semibold 等宽 + 单位 11。
- 线性进度：高 4、圆角 2，底色 `field`，填充品牌蓝。
- 播放进度条：常态高 4，拖动时变 6。
- 分段比例条（容量构成）：高 8，段间空隙 2，最多 3 种颜色。
- 无数据：环/条置灰并写「暂无数据」，不显示 0%。
- 首版图表只用单色条形，不加坐标轴装饰与图例。

### 5.12 空态 / 加载 / 错误

| 类型 | 结构 | 必须有 |
| --- | --- | --- |
| 空 | 40pt 线性图标（`secondaryText`）+ 17 Medium 标题 + 14 说明 | 一个动作按钮 |
| 加载 | 骨架（行或卡片），不用整页菊花（首次冷启动除外） | 与真实布局同尺寸 |
| 错误 | 40pt 图标 + 16 原因 + 14 下一步 + 主按钮重试 | 重试或改设置 |

- 骨架：`field` 色块，圆角随宿主；微光 1.2s 循环，减弱动效时静态。
- 空态在内容区垂直居中，距顶 ≥ 80；不在空态里放广告或引导图。
- 文案必须写清原因与出口，禁止「暂无数据」这类无信息文案。

### 5.13 滑动操作与长按菜单

- 右侧滑动只放 1 个主操作（删除，红色）；左侧最多 2 个。
- 滑动按钮为图标 + 文字，与行同高，不缩放不旋转。
- 删除必须二次确认；只删本地记录时要写明「不会删除云端文件」。
- 长按菜单用 `contextMenu`，最多 5 项，危险项放最后并标红。
- 拖拽排序只用于用户自定义列表；首版不做拖拽。

### 5.14 筛选与排序

- 入口在顶栏下方一行 chips（可横滑）或工具条「筛选」按钮。
- chip：高 32、圆角 16；选中 `brandBlue 12%` 底 + 品牌蓝字。
- 排序用 `.sheet` medium，单选 + 勾选，选择后立即生效并关闭。
- 已生效筛选在入口显示数量（如「筛选 · 2」）。
- 筛选变化不整页刷新，列表 150ms 淡入。

### 5.15 徽标与角标

- 数字角标：红底白字，高 18、最小宽 18，超过 99 显示 `99+`。
- 状态点：8pt 圆点 + 2pt 白描边，用于在线 / 离线。
- Tab 角标首版只用小圆点，不用数字。

### 5.16 文本与截断

| 场景 | 行数 | 溢出处理 |
| --- | --- | --- |
| 列表标题 | 1 | 尾部截断 |
| 列表副标题（文件名） | 1 | 中部截断，保留扩展名 |
| 卡片标题 | 2 | 尾部截断 |
| 说明 / 帮助文本 | 3 | 尾部截断，完整内容进详情页 |
| 空态 / 错误说明 | 2 | 居中换行，不截断 |

- 文件路径保留首尾段（`/电影/…/S01E02.mkv`），不从头截断。
- 不缩小字号、不压缩行高来塞长文本；宁可截断也不做单行 10pt。
- 数值与单位不断行（`3.2 GB` 整体换行）；时间与时长同理。
- 中文标点不置于行首、数字不与单位分离，交给系统排版，不自绘换行。

## 6. 页面视觉

> 标注：`已实现` 表示当前代码已有；`规划` 表示目标态，落地时按本规范执行。

### 6.1 启动页（已实现）

- 结构：白底到浅蓝渐变 + 四层波浪 + Logo + `RexHub` + 副标题，支持减弱动效。
- 时序：波浪与品牌入场保留；**总停留由会话恢复驱动，最短 300ms、校验最多 1.5s**；有 token 直接进首页（校验失败落离线态），无 token 淡入登录页。
- 不允许"登录页闪一下又跳走"，也不允许用固定 sleep 假装加载。

### 6.2 登录页（已实现，忘记密码/发现设备待接）

- 结构：品牌方块 → 名称 → 服务端地址 → 账号 → 密码 → 记住密码/忘记密码 → HTTPS 开关 → 主按钮 → 发现局域网设备。
- 布局：左右边距 20，字段间距 12，输入框高 56、圆角 14、1.5pt 聚焦描边，主按钮高 54。
- 进入页面不自动弹键盘，点击输入框才聚焦，避免首屏被遮挡。
- 焦点链路：服务端 `.next` → 账号 `.next` → 密码 `.go`；`.go` 在必填项完整时提交，不完整时只收起键盘。
- 点击输入框以外的空白处：失焦、蓝描边消失、键盘收起（通用规则见 12.1）。
- 密码可见按钮只切换明文，焦点与键盘保持不变，命中区 44×44。
- 请求中按钮内嵌菊花并禁用；失败保留已填内容，原因以 12pt 红字显示在密码框与「记住密码」之间，不弹窗。
- 现状：以上交互已实现；「记住密码」已持久化（账号存 UserDefaults、密码存 Keychain 独立 key，取消勾选即删除）；「忘记密码」无动作；「发现局域网设备」仅收起键盘。
- 待实现：忘记密码引导、设备发现与权限拒绝提示。

### 6.3 首页（已实现骨架；当前 4 Tab：影视 / 短剧 / 网盘 / 更多）

现状：

- 顶栏：影视首页用品牌工具条 `RexTopBar`（唯一例外），固定在安全区下方、不随内容滚动。展开态 = Logo 36 +「RexHub」20 Semibold + 问候 + 在线状态胶囊 + 首字母头像，下方接 44 高搜索框（`field` 填充、聚焦品牌蓝描边）；内容滚动超过 8pt 收拢为 52 高单行（Logo 28、标题 17、问候与搜索框收起、右侧出现搜索图标），铺 `surface` 底 + 1px `divider`，200ms 渐入（规则见 5.7）。
- 内容区（影视 Tab）：首页栏目区（标题 18 +「管理」文字按钮 + 空态卡：64 图标底 +「暂无栏目」+ 说明 + 全宽渐变按钮「去配置」）→ 服务端卡（「当前连接」+ 地址中部截断 + 箭头，点击进更多）。首页不出现「绑定 115」按钮。
- 短剧：一级占位页（`PlaceholderView`），顶栏通用工具条 `RexNavBar(title: "短剧")` **不显示返回**，内容为 64 图标底 + 一句说明的空态卡；网盘已接真实目录（见 6.4）。
- 更多：一级页，顶栏 `RexNavBar(title: "更多")`，**不显示返回**；已按 9 组结构实现：服务状态卡 + 常用功能快捷入口 + 七组设置（详见 6.7）。
- 导航语义：每个 Tab 各自包一个 `NavigationStack`（`.toolbar(.hidden, for: .navigationBar)`），Tab 根页一律 `leading: .none` 无返回；后续 push 的二级页用 `RexNavBar` 的 `.back` 形态，点击 `dismiss()` pop 回上一页，保留系统侧滑。
- 底部 Tab：系统 `TabView`，顺序固定「影视 / 短剧 / 网盘 / 更多」；选中填充 + 品牌蓝，未选中线性；点当前 Tab 回顶并给 `.light` 触感（规则见 5.5）。
- 宽度：内容最大 720 居中，iPad 不拉满；`scrollDismissesKeyboard(.interactively)`。
- 待补：真实健康检查驱动状态位（在线 / 未连接 / 同步 / 存储告警）、栏目海报墙与栏目配置、短剧与网盘的真实内容。

目标结构（按产品需求：可配置栏目海报墙，不是媒体库）：

```text
[Logo + RexHub + 问候]                    [头像]
[搜索影视资源............................]
热门电影        横滑海报墙                查看全部 ›
最近更新剧集    横滑海报墙                查看全部 ›
高分电影        网格海报墙
……（栏目由用户在 iOS 端配置：新建 / 排序 / 显示隐藏 / 数据类型 / 数量 / 布局）
[影视] [短剧] [网盘] [更多]
```

- 栏目数据来自影视元数据 Provider，不人工维护；可用类型：热门电影、近期电影、热门电视剧、最近更新剧集、高分电影、动漫及其他可配置分类。
- 栏目配置完全在 iOS 内完成，NAS 只保存配置并按配置返回数据；Web 不提供首页可视化编辑器。
- 顶栏搜索框进入**全局资源搜索**（纯资源搜索），不混入影视元数据搜索。
- 首页不做「继续观看 / 存储环 / 快捷分类」等媒体库式模块；继续观看属于播放历史，入口在「更多」。
- 115 授权在 Web 管理端完成，iOS 不保存凭证，首页不出现「绑定 115」按钮；服务未配置时给只读说明并指向管理台。
- 海报卡 2:3、圆角 16，标题最多两行；加载失败用类型图标占位，不留白块。

### 6.4 网盘页（已实现骨架；对应「网盘」Tab）

- 现状：一级页，通用工具条 `RexNavBar(title: "网盘")` + 右侧快捷操作「刷新」；读取服务端已绑定的 115 目录，文件夹逐级 push（子页顶栏 `leading: .back`，只有返回图标），点文件进入全屏播放。空态「此文件夹为空」，失败卡给「重试」。
- 列表行：36pt 图标块 + 名称（最多两行）+ 副标题（文件夹显示「文件夹」，文件显示「大小 · 修改时间」）+ 文件夹右侧箭头；整卡白底、1pt `divider` 描边，行间分隔线左缩进 64。
- 播放不中转：服务端只返回临时直链与请求头，播放器直连 115 CDN；直链过期或解析失败后由失败页「重试」重新解析。
- 顶部导航栏「网盘」+ 账号切换 / 排序；搜索框独立一行。
- 支持多账号：当前账号、默认账号、授权状态与「重新授权」，凭证只在 NAS，iOS 不展示 Cookie / Token。
- 转存任务区：进行中 / 成功 / 失败，可查看结果；不做批量任务管理。
- 不做「已下载 / 离线下载」入口（产品不支持 App 本地视频下载）；「收藏」属于影视作品，不放网盘页。
- 列表按「文件夹优先 → 名称」排序；文件夹右侧箭头，文件右侧大小/时间。
- 支持下拉刷新、长按菜单（重命名、移动、删除）。
- 滑动删除只删本地记录时，文案要说明"不会删除网盘文件"。

### 6.5 全局资源搜索页（规划）

- 定位：**纯资源搜索**，不混影视元数据搜索；从首页搜索框进入，进入即聚焦，键盘 `.search`，右侧「取消」。
- 空查询：搜索历史（单条删除 / 清空）+ 热门关键词；不做关键词收藏与统计。
- 发起搜索：多来源并发，结果按来源逐步返回；顶部来源状态条显示等待 / 搜索中 / 已完成 / 失败 / 已取消，可单独重试或刷新某个来源。
- 缓存：先展示缓存结果并标注缓存时间；不自动全量重搜，用户下拉或点「刷新」才重新请求，支持单来源刷新。
- 结果行：资源标题（最多 2 行）+ 来源名 / 类型 / 大小 / 文件数 / 更新时间；行内快捷操作：复制链接、115 转存、网盘在线、在线播放、详情。
- 准确性优先：默认只展示明确匹配的资源；续作、同系列、相似名称收进「显示更多相关结果」，展开后标注关联类型。
- 取消：支持取消全部与取消单来源；取消不清空已返回结果，取消与失败文案必须区分。
- 无结果：给建议与筛选入口，不用无关资源填充列表。
- 筛选：来源、资源类型、文件大小（仅来源提供数据时可用）；不提供清晰度 / 编码 / 字幕语言 / 音轨语言的通用筛选。
- 排序：综合排序，准确性优先，不因标题关键词相似而提升排序。

### 6.6 播放页（规划）

- 进入横屏全屏、隐藏状态栏、纯黑背景，海报与视频是唯一视觉重心。
- 控制层 3 秒自动隐藏；点按切换显隐。
- 控制层：返回 + 标题 / 中央播放暂停 / 底部进度 + 时间 / 工具条（倍速、音轨、字幕、画中画）。AirPlay 第一阶段不实现，不占位。
- 手势：左右滑快进快退（浮层显示秒数）、上下滑亮度/音量、双击左右 ±10s。
- 缓冲：居中菊花 + 半透明黑底，不改变画面亮度。
- 网盘在线：进入播放器立即显示「正在准备播放」+ 阶段（正在转存 / 正在解析播放地址），可「取消等待」，后台转存继续；地址就绪自动起播。
- 准备失败：给「重试 / 换源」，不无限转圈；退出播放器不取消转存，再次进入按播放会话恢复状态。
- 磁力：后端能解析则直接播；不能解析时提示「转存到 115 后播放」，不做 BT 流媒体。

**设计原则**

- 不给每个设置项单独做一张大卡片；同一分组共用一张面板。
- 不做九宫格功能菜单；快捷入口最多一行四项。
- 不使用大面积彩色渐变与玻璃效果；玻璃只用于有层次意义的悬浮区域（如播放器控制层）。
- 标题、说明、状态、箭头严格对齐：图标 28 宽 + 12 间距 + 文本，箭头右对齐 16。
- 危险操作（退出登录、清除全部缓存、解绑账号）独立成组，红色文字 + `alert` 二次确认。

**二级页面规则**

- 一级页只放分类入口，复杂配置一律进二级页；二级页沿用同一套分组面板，不另起视觉风格。
- 二级页顶栏用 `RexNavBar(title:, leading: .back)`，标题与入口名一致。
- 开关类改动即时生效并落盘，不给「保存」按钮；只有需要提交的页面才在底部放主按钮。
- 条目顺序：常用项在前、高级项在后、危险项单独一张卡。

### 6.8 影视作品详情页（规划）

**电影**

```text
[背景图 + 海报 2:3]  作品名 / 原名 / 年份 / 类型 / 评分
                    简介（3 行，可展开）· 演员
                    [网盘在线] [收藏]
```

- 元数据来自 Provider，图片优先使用 Provider 原图；加载失败用占位图。
- 资源列表复用 6.5 的结果行与操作菜单；搜索状态复用来源状态条。
- 默认只展示严格匹配资源；「显示更多相关结果」入口放在列表末尾。

**电视剧 / 动漫**

- 基本信息 → 季选择（单季时不显示）→ 剧集列表 → 整季资源。
- 默认展示整季资源；点击某一集，从底部弹出资源面板，展示该集资源，关闭后仍留在详情页。
- 整季与单集资源必须有明确分组标题，不能混排。
- 文件名识别到 `S01E01` / `01x03` / `第01集` 时标注季集；识别失败保留原始文件名，不报错。

**多磁力多选转存**

- 只在同一作品或同一季资源组内出现「多选」入口；不提供跨作品批量操作。
- 多选态：行首圆形勾选、底部操作条显示「已选 N 项」+「全选 / 取消」+「转存」。
- 一次提交多条磁力，共用本次目标目录；结果按条展示成功 / 失败，不因单条失败回滚全部。

### 6.9 资源详情页（规划）

独立完整页面，不用底部弹窗代替。

```text
[海报 / 封面 / 截图]   完整资源名称
                      来源 · 类型 · 更新时间 · 大小 · 文件数
[复制链接] [115 转存] [网盘在线] [在线播放]
文件列表（只读）
来源扩展信息（可折叠）
```

- 文件列表只展示文件名、格式、大小，不提供文件级播放 / 转存 / 重命名。
- 来源扩展信息：来源特色字段、分享信息、磁力哈希、原始返回（折叠）、来源更新时间。
- 图片优先资源自身提供；无图时可用元数据补图，但不得错误关联。
- 不做评论、评分与评价入口。

### 6.10 短剧页（规划）

- 独立一级页，通用工具条 `RexNavBar(title: "短剧")`，内容为插件来源提供的短剧列表（海报墙 / 列表可切换）。
- 详情页：短剧信息、剧集列表、播放地址由插件返回；不同来源统一为标准结构，页面不为单个来源写分支。
- 播放复用主播放器、字幕、播放历史与进度；支持独立私密模式。
- 插件未配置或全部失败：空态说明原因 + 「去管理台配置」，不展示假数据。

### 6.11 私密模式（规划）

- 隐藏式入口，界面不出现「私密」文字；触发后先做身份验证。
- 验证：Face ID 优先；不可用或失败时用独立数字密码；连续失败给冷却提示。
- 进入后栏目、收藏、播放历史、搜索历史、字幕库与缓存全部切到私密空间，视觉上不额外加「私密」标签。
- App 切后台或锁屏自动退出；退出后相关内容立即不可见，不保留缩略图与进度。
- 私密空间内不展示常规模式入口；切换作用域时清空列表并回到根页。

### 6.12 字幕面板（规划）

- 播放器工具条「字幕」打开 `.sheet`（medium / large），不离开播放页。
- 结构：当前字幕 / 关闭字幕 → 自动推荐（匹配度最高）→ 全部结果（语言、格式、来源、版本、匹配度、更新时间）。
- 多来源并发搜索：来源状态条复用 6.5 规则，可单来源重试。
- 只支持单条下载，下载完成后自动加载并切换；不提供批量下载。
- 字幕样式（字号、颜色、位置、背景、时间轴偏移）在同一面板的二级页调整。
- 无结果：给「换个关键词」与「导入本地字幕」两个出口；本地导入只影响当前播放。

### 6.13 115 转存目录选择器（规划）

- 触发：对应页面未配置转存目录时，点击转存立即弹出目录选择 `.sheet`。
- 结构：目录面包屑 + 文件夹列表 + 「新建文件夹」+ 底部「转存到此目录」。
- 本次选择只对本次转存生效，不自动写入默认配置；提供「设为默认」开关但默认关闭。
- 多条磁力多选转存共用同一次选择结果。
- 目录加载失败：给「重试 / 返回上级」，不关闭已选中的目录。

| 网盘列表 | 骨架行 ×6 | 「此文件夹为空」 | 重试 + 返回上级 | 缓存 + 禁止操作提示 |
| 播放 | 缓冲菊花 + 准备态文案 | — | 重新解析 / 换源 / 重试 | 「已离线，无法播放」 |
| 字幕搜索 | 行内菊花 | 「没有找到字幕」+ 换关键词 | 该来源失败 + 重试，其他来源结果保留 | 提示需联网，已下载字幕可用 |
| 短剧列表 | 骨架海报卡 | 「该来源暂无短剧」 | 来源失败 + 重试 | 缓存 + 顶部离线条 |
| 更多 | 直接渲染 | — | 行内提示 | 标记"未连接" |

失败路径必须逐类给出口（这是"成熟"与"Demo"的分界线）：

| 失败原因 | 用户可见出口 |
| --- | --- |
| 115 直链过期 | 「重新解析」 |
| 网盘风控 / Cookie 失效 | 「重新授权 115」（授权在 Web 管理端完成） |
| 转存失败（空间不足 / 已存在 / 风控） | 按条展示原因，给「重试该条」或「更换目录」，不回滚其他条目 |
| 播放会话过期 / 解析超时 | 「重新解析」，停止轮询，不无限转圈 |
| 磁力来源无法直接播放 | 说明需先转存 115，给「去转存」 |
| 格式不支持 | 提示播放内核暂不支持，给「换源」 |
| 字幕来源失败 | 只标记该来源失败，其他来源结果保留 |
| 无权限 | 说明缺哪个权限，给"去设置" |
| 网络不可达 | 「检查服务端地址」+ 重试 |

规则：错误文案必须包含**原因 + 下一步**；空态必须包含**一个动作**；禁止无限转圈。

## 8. 可访问性与适配

### 8.1 无障碍基础

- 正文使用可缩放字体，AX5 下不截断、不重叠。
- 图标按钮必须有 VoiceOver 标签；列表行合并为一个元素，朗读"标题、副标题、状态"。
- 自绘控件给 `accessibilityValue`（如环形进度读"已用 68%"）；动态结果变化发 announcement。
- 正文对比度 ≥ 4.5:1，状态不能只靠颜色区分（配文字或图标）。
- 命中区 ≥ 44×44；深浅色只使用语义色。

### 8.2 尺寸与方向

- iPhone 竖屏为设计基准；工具页不强制横屏布局，横屏时内容单列居中。
- 播放页横屏沉浸、隐藏状态栏；方向锁定时不因输入法引起布局跳动。
- 状态栏样式跟随语义色（浅色页深色字）；沉浸页隐藏，轻点一次唤出。
- 内容不压 Home Indicator；顶部遵守安全区（播放页与全屏图除外）。
- 键盘弹出时聚焦字段可见，提交按钮可滚动到；键盘不推挤顶栏，只有内容区避让。

### 8.3 iPad 与多任务

- 宽 ≥ 768 用 `NavigationSplitView`：侧栏 320（影视 / 短剧 / 网盘 / 更多），详情区最小 480。
- 详情内容最大宽 720 居中；海报网格 5–6 列，卡片间距沿用 12。
- Slide Over / 窄分栏（宽 < 500）退化为单列 + Tab，不出现被压扁的双栏。
- 外接指针：hover 只加 2% 高亮，不放大、不位移、不加光圈。
- 多窗口（规划）：每窗口独立导航栈；首版不做多窗口。

### 8.4 动态字体

- 字号在 `RexFont` 内映射为 Dynamic Type 相对字号，只有品牌字与装饰数字固定。
- AX3 起：列表行高自适应、按钮高度随文字增长、双列卡片退单列、顶栏退化为"标题 + 状态圆点"。
- 放大后不允许：文字压图、按钮文字竖排、标签被截成单字、图标与文字错位。
- 验收档位：Default / AX1 / AX3 / AX5（见第 10 节）。

### 8.5 多语言与 RTL

- 布局用 leading / trailing，不用 left / right；镜像只对方向性图标（返回、箭头），播放、音量等不镜像。
- 文案不拼接字符串（"共 N 项"用格式串），复数走 String Catalog 变体。
- 预留英文膨胀 ×1.3、德文 ×1.5 的宽度；按钮文字最多两行。
- 数字、时间、文件大小走 `formatted()`，不手写拼接。
- 首版仅简体中文，但代码按多语言结构书写（String Catalog，规划）。

### 8.6 系统辅助功能

| 设置 | 表现 |
| --- | --- |
| 减弱动效 | 关闭位移、缩放与循环动画（含骨架微光、启动页波浪） |
| 增强对比度 | 描边 1px → 2px，半透明底色提高到 ≥ 12%，次要文字提亮 |
| 减弱透明度 | 半透明层改不透明 `surface` + 描边 |
| 深色模式 | 不叠阴影，改描边（见 4.9） |
| 更大指针（iPad） | 命中区不变，hover 高亮不放大 |

## 9. 实现约定

### 9.1 代码

- 颜色、字号、间距、圆角一律引用 `RexTheme`，组件内不写字面量；页面级特殊尺寸（主按钮高 54、品牌区留白 48–64）允许在页面内声明，需集中书写并注释用途。
- 可复用视图控制在 50 行内；页面用组合，不写巨型 View。
- 列表统一 `LazyVStack / LazyVGrid`，缩略图异步加载 + 内存缓存。
- 组件状态用枚举表达（默认 / 按压 / 聚焦 / 禁用 / 加载 / 错误），不用多个布尔量互相覆盖。
- 字符串走 String Catalog（规划）；数据请求与状态管理见 [架构文档](./ios-app-blueprint.md)。

### 9.2 设计交付与预览

- 每个可复用组件至少一个 `#Preview`，覆盖：浅色 / 深色；表单类另加出错态与禁用态，列表类另加空态与加载态。
- 新组件先进预览聚合页（`DesignGalleryView`，规划），通过后再接入业务页面。
- 改 Token 必须同时改 `RexTheme.swift` 与本文件 §4，不允许只改一处。
- 验收截图：iPhone 393×852 与 iPad 分栏各一套，浅色 + 深色，逐项对照第 10 节。
- 动效与触感只在真机验收，模拟器结果不作依据。

### 9.3 资源

- 图片进 Assets，命名 `{模块}_{用途}`，不把界面文字做进图片（无法本地化）。
- 品牌 Logo、启动页波浪使用矢量或 PDF 资源，避免多倍图模糊。
- 海报与封面走异步加载 + 内存缓存，降采样规则见 5.10。

## 12. 交互细节规范（全页面通用）

> 视觉决定"看起来对不对"，交互细节决定"用起来顺不顺"。本节是跨页面的硬规则，页面章节只写差异，不重复。

### 12.1 焦点与键盘

| 操作 | 应有行为 |
| --- | --- |
| 点击输入框 | 获得焦点，显示 1.5pt 蓝色描边，弹出键盘 |
| 点击输入框以外的空白处 | 失焦、描边消失、光标隐藏、键盘收起、内容回位 |
| 点击另一个输入框 | 焦点直接转移，键盘保持不闪动 |
| 键盘「下一项」 | 按字段顺序流转 |
| 键盘「前往 / 完成」 | 收起键盘并触发提交（表单允许时） |
| 拖动页面 | 键盘跟随手指交互式收起 |
| 提交 | 先收起键盘，再发请求 |
| 页面离开（push / sheet / 切 Tab） | 收起键盘，返回后不自动恢复焦点 |
| 进入页面 | 不强制弹键盘，避免首屏被遮挡；是否自动聚焦按页面约定 |

- 收起键盘的点击层必须放在内容**下层**，只承接空白区域。禁止给输入框的父容器整体加 `onTapGesture`，否则点输入框会立刻收起键盘。
- 键盘弹出后聚焦字段必须可见（系统自动滚动避让）；主按钮允许暂时被键盘遮住，但页面必须能滚动到它，键盘收起后立即可见。

### 12.2 点击区域

- 所有可点元素命中区 ≥ 44×44，视觉尺寸可以更小。
- 输入框以整行文字区域为热区；行内图标按钮（密码可见）只触发自身动作，不改变焦点。
- 列表行整行可点，右侧箭头不作为独立热区。
- 禁止"看起来能点但没反应"的区域；不可用状态要么禁用点击，要么给出原因。

### 12.3 提交与重复触发

- 提交中：按钮内嵌菊花、整体禁用、不响应重复点击。
- 校验时机：格式错误在失焦时提示；必填缺失在提交时提示；输入过程中不打断。
- 失败：保留已填内容，错误显示在相关字段下方，不弹窗、不清空。
- 成功后直接跳转，不闪回可点击态。

### 12.4 手势冲突

- 保留系统侧滑返回、下拉刷新、长按菜单，不覆盖系统手势。
- 自定义手势与屏幕边缘保持 ≥ 20pt 间距，避免抢系统返回。
- 同一区域只允许一个手势优先级：滚动 > 点击 > 长按。

### 12.5 状态保持

- 切后台、来电、控制中心返回：输入内容保留，焦点按系统策略恢复。
- 页面返回：列表滚动位置、筛选条件、未提交表单不丢失。
- 仅退出登录时清空账号相关的敏感输入。

### 12.6 反馈与触感

- 破坏性操作二次确认；成功用轻触感 + 轻提示，失败用行内文案。
- 同一时刻只显示一个 Toast / 一条错误，不叠加。
- 动效遵循 4.5；减弱动效开启时取消位移与循环动画。

### 12.7 输入辅助

| 字段 | 键盘 | 附带规则 |
| --- | --- | --- |
| 服务端地址 | `.URL` | 不自动大写、不纠错；接受 `IP:端口`、域名、完整 URL；失焦时校验 |
| 账号 | `.asciiCapable` | `.username` 内容类型，支持密码管理器填充 |
| 密码 | `SecureField` | `.password` 内容类型；可见切换不改焦点、不重弹键盘 |
| 搜索 | `.search` | 回车即搜索，带清除按钮，无结果显示建议 |

- 必填缺失时按钮置灰，不用弹窗提示"请填写"。
- 输入过程中不打断校验，失焦或提交时才提示。
- 外接键盘：Tab 在字段间移动，Esc 收起键盘，均为系统行为，不覆盖。
- 提交统一先失焦，避免键盘与错误提示同时出现。
- 长度上限在输入时静默截断，超限时给一次行内提示；只有业务确需计数（如 `0/60`）才显示字数，其余不显示。

### 12.8 加载与刷新

- 有缓存直接渲染旧数据，不闪骨架；无缓存才显示骨架。
- 下拉刷新不清空现有内容；失败保留旧数据 + 行内提示。
- 分页加载：底部菊花 → 到底显示"没有更多了"。
- 只有首次进入允许整屏 loading，局部刷新不整页转圈。
- 超过 8s 未返回要给出"仍在加载"说明或取消入口，禁止无限转圈。

### 12.9 提示层级

| 层级 | 用途 | 表现 |
| --- | --- | --- |
| 行内 | 字段错误、请求失败 | 常驻到修复或重试 |
| Toast | 复制成功、已加入队列 | 顶部安全区下方，2s 自动消失 |
| 弹窗 | 删除、解绑、退出登录 | 必须用户确认 |
| 全屏 | 首次引导、115 授权 | 有明确退出路径 |

- 新 Toast 顶替旧 Toast，不排队堆叠。
- 破坏按钮用动词（"删除""退出"），不写"确定"。
- 错误文案 = 原因 + 下一步（"地址无法连接，请检查服务端是否启动"），禁止只写"失败"。
- 页面切换：push 用系统转场，播放页自定义淡入；Tab 切换保留各自滚动位置，不重建列表。

### 12.10 滚动与内容定位

- 保留系统「点状态栏回到顶部」；同屏只有一个滚动视图时生效，嵌套横滑列表不抢这个行为。
- 下拉刷新只在一级列表（影视、网盘）启用，详情页与播放页不启用。
- 横滑轮播（最近添加 / 继续观看）用 `scrollTargetBehavior(.viewAligned)`，一屏露出 2.2 张卡片暗示可滑。
- 滚动条用系统默认，只在长列表出现；不自定义颜色、不常驻显示。
- 滚出视口的缩略图取消请求，回到视口再加载；不预加载全屏量级的图。
- 刷新失败、翻页失败都不回到顶部；已读位置以用户手动滚动为准。
- 键盘收起后内容回到原滚动位置，不因避让产生跳动。

## 13. 权限与系统弹窗

| 权限 | 申请时机 | 拒绝后的处理 |
| --- | --- | --- |
| 本地网络 | 首次「发现局域网设备」或连接局域网服务端时 | 说明用途 + 「去设置」；仍可手动输入地址 |
| 相册 | 首次「保存图片 / 上传封面」时 | 「去设置」；其余功能不受影响 |
| 通知 | 「更多」页主动开启，不在首次启动时弹 | 开关保持关闭，随时可再开 |
| 剪贴板 | 用户主动粘贴时（系统自动提示） | 无额外处理，不影响主流程 |

- 首次启动不批量申请权限；一次只申请一个，弹窗前先用一行文案说明用途。
- 系统只给一次弹窗机会：被拒后不再依赖系统弹窗，改为行内提示 + 「去设置」跳转。
- 权限被拒只禁用依赖该权限的具体动作，不锁整页、不阻塞浏览。
- 播放页不申请任何权限；后台播放涉及的音频会话另行说明（见架构文档）。
- 系统弹窗出现前先收起键盘，避免弹窗与键盘叠在一起；弹窗期间不显示 Toast。

## 14. 文案规范

**基调**

- 简体中文、短句、动词开头；不用「哦 / 啦 / 呢」等口语尾巴，不用感叹号堆情绪。
- 称呼用户用「你」；不使用「亲」「小主」这类拟人称呼。

**按钮与操作**

- 按钮用动词 + 对象：`保存` / `删除栏目` / `重新解析` / `前往设置`，主按钮 2–4 字。
- 破坏性按钮写清后果：`退出登录` / `删除 3 个文件`，不用「确定」代替。
- 同一动作全 App 用同一个词，不做「刷新 / 重新加载」混用。

**术语统一**

| 统一用词 | 不用 |
| --- | --- |
| 服务端 | 服务器、后端、服务 |
| 栏目 | 分区、板块、媒体库 |
| 资源 | 磁力、链接、种子（作为通用称呼时） |
| 资源来源 | 资源站、渠道、源站 |
| 115 网盘 | 115、网盘（指代其他服务时除外） |
| 离线缓存 | 下载缓存、本地缓存 |
| 剧集 | 电视剧、连续剧 |
| 账号 | 帐户、账户 |

**错误与空态**

- 错误 = 原因 + 下一步：`地址无法连接，请检查服务端是否已启动`。
- 禁止无信息文案：`操作失败` / `出错了` / `未知错误` / `网络异常`（单独出现时）。
- 空态 = 现状 + 出口：`还没有栏目` + `在「栏目配置」里添加影视分类` + 动作按钮；搜索空态用 `没有找到匹配资源` + `换个关键词，或检查资源来源是否已启用`。

**格式与标点**

- 成功提示 ≤ 8 字且不加句号：`已复制` / `已加入队列`。
- 省略号用 `…`（U+2026），不用 `...`；加载文案统一「加载中…」。
- 中文用全角标点，句中英文与数字用半角；标题、按钮、Toast 末尾不加句号，说明文字可加。
- 数值与时间格式遵循 4.8；不出现「刚刚」「一会儿」这类无法量化的时间词。
